# MCP Overview

Use MCP/tooling only to strengthen evidence and speed, not to bypass repo-local rules.

In this repo, the most relevant tool lanes are:

- browser automation for UI validation,
- git/status/diff commands for release hygiene,
- image/design tooling only when UI work is substantial and project-local design guidance exists.

If a tool output conflicts with repo-local docs, the docs win until updated.
