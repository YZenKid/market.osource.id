# MCP and Tooling Posture

- Prefer local repo inspection and repo-local docs before external research.
- Use browser automation for UI validation only when the app is runnable and screenshots materially improve confidence.
- Use image generation or Stitch-assisted design work only for substantial UI tasks; `DESIGN.md` still governs local direction.
- GitHub workflow state should be checked against files under `.github/workflows/` before making claims about CI.

This repo already carries OpenCode plans and evidence under `.opencode/`; keep new tool output aligned with that structure.
