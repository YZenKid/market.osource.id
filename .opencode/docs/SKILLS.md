# Skills

Use the OpenCode orchestrator skill/workflow as the default entrypoint for coding tasks, then route to bounded specialist lanes.

Most important lane ownership in this repo:

- routing/integration → `@orchestrator`
- planning → `@artifact-planner`
- bounded implementation/tests → `@fixer`
- architecture/review → `@oracle`
- UI/UX → `@designer`
- discovery/docs research → `@explorer`, `@librarian`
- final signoff → `@quality-gate`
