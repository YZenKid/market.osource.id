# Prompt Gates

Ask before proceeding when a change would:

- alter product scope, canonical statuses, or data model semantics
- change the locked stack or runtime model
- introduce SaaS assumptions, self-service seller signup, or dynamic plugin runtime
- replace existing project-specific rules without approval

Do not invent long-form local policy when a root doc already exists.
If project docs conflict, resolve the docs or ask; do not silently choose one.
For substantial UI work, read `DESIGN.md` first and route through `@designer`.
