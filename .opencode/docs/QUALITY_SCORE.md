# Quality Score

Use this lightweight scorecard before calling non-trivial work done:

- Scope matched the request and canonical docs
- Relevant validation commands ran or were explicitly deferred
- Evidence exists under `.opencode/evidence/` when the task is material
- Security-sensitive changes received security-aware review
- UI changes include runnable evidence when applicable
- Remaining risks are stated plainly

If several items are missing, report the task as draft, blocked, or partial instead of done.
