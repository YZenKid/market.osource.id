# Agent Legibility

Every material task should make ownership obvious:

- who routed the work,
- which specialist owned research/implementation/review,
- what evidence was produced,
- which residual risks remain.

When many agents are available, future operators should read `AGENT_ROUTING.md` and `SKILLS.md` before starting broad work.

Keep handoffs file-path based and scoped. Prefer references like `apps/web/package.json` or `docs/deployment/vps.md` over pasted long excerpts.
