# Security Threat Models

Dokumen di folder ini merangkum threat model opsional-praktis untuk area Gate I yang paling berisiko pada `market.osource.id`.

Tujuan dokumen ini:

- memberi checklist implementasi dan review yang singkat,
- membantu operator memahami batas aman deployment self-hosted,
- memastikan keputusan produk di PRD/TRD tetap diterjemahkan menjadi kontrol operasional.

Dokumen tersedia:

- `threat-model-payment-proof.md`
- `threat-model-tunnel.md`
- `threat-model-desktop-db.md`
- `threat-model-entitlement-privacy.md`
- `threat-model-install-lock.md`
- `threat-model-diagnostics-redaction.md`

Semua threat model di sini bersifat **concise but actionable**: bukan audit formal penuh, tetapi cukup untuk release checklist, issue creation, dan reviewer handoff.
